# 📖 Sobre o Projeto

O **Chama no Pet** é um sistema desenvolvido com o objetivo de auxiliar no **gerenciamento de pets e no controle de atendimentos veterinários**.

A aplicação permite cadastrar e gerenciar informações relacionadas aos animais, facilitando a organização dos dados e o acompanhamento dos atendimentos realizados.

O projeto foi desenvolvido utilizando **ASP.NET Core** como tecnologia principal para construção da aplicação, **C#** como linguagem de programação e **SQL Server** para armazenamento e persistência dos dados.

O sistema tem como proposta proporcionar uma solução simples e organizada para o gerenciamento das informações de uma rotina de atendimento veterinário.

---

# 🚀 Funcionalidades

O sistema possui as seguintes funcionalidades:

- ✅ Cadastro de pets
- ✅ Consulta de pets cadastrados
- ✅ Visualização dos detalhes dos pets
- ✅ Edição de registros
- ✅ Exclusão de registros
- ✅ Gerenciamento das informações dos animais
- ✅ Persistência dos dados em banco de dados
- ✅ Integração com SQL Server
- ✅ Operações CRUD
- ✅ Controle de informações dos pets

# 🗄 Banco de Dados

A aplicação utiliza o **SQL Server** para armazenamento e persistência das informações.

O acesso ao banco de dados é realizado utilizando o **Entity Framework Core**.

O banco de dados é responsável por armazenar as informações relacionadas aos pets cadastrados no sistema.
