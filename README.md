# 📖 Sobre o Projeto

O **Chama no Pet** é um sistema desenvolvido com o objetivo de auxiliar no **gerenciamento de pets e no controle de atendimentos veterinários**.

A aplicação permite realizar operações de **CRUD (Create, Read, Update e Delete)** para o gerenciamento das informações dos animais.

O sistema também tem como objetivo auxiliar no controle dos **atendimentos veterinários**, permitindo organizar as informações relacionadas aos pets e seus respectivos atendimentos.

O projeto foi desenvolvido utilizando **ASP.NET Core MVC**, com **C#** como linguagem principal e **SQL Server** como banco de dados.
